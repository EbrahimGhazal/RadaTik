1. نظرة عامة

RadaTik هو نظام متكامل لإدارة مزود خدمة الإنترنت (ISP) مبني على تقنيات Microsoft الحديثة. يوفر النظام إدارة شاملة للعملاء، المخدمات، القطاعات، المستقبلات، البروفايلات، والاشتراكات مع دعم كامل للتكامل مع أجهزة MikroTik.

الهدف من النظام

  • إدارة شاملة لعمليات مزود خدمة الإنترنت
  • تتبع العملاء والاشتراكات
  • إدارة المخدمات والبنية التحتية
  • مزامنة تلقائية مع أجهزة MikroTik
  • نظام متعدد المستأجرين (Multi-tenant)
  • واجهة مستخدم عصرية وسهلة الاستخدام

3. الأدوار والمستخدمين

يحتوي النظام على أربعة أدوار رئيسية، كل دور له صلاحيات ووظائف محددة:

3.1 مدير النظام (SystemAdministrator)

الدور: المستوى الأعلى في النظام، يدير جميع مديري الشبكة والشبكات.

الصلاحيات:

  • إدارة طلبات مديري الشبكة (قبول/رفض)
  • عرض جميع الشبكات ومدراء الشبكة
  • إحصائيات شاملة لجميع الشبكات
  • إدارة الحساب الافتراضي

الوظائف المتاحة:

1. إدارة طلبات مديري الشبكة
  • المسار: /SystemAdmin/NetworkAdminRequests
  • الوصف: عرض جميع طلبات إنشاء حساب مدير شبكة
  • الإجراءات:
    • عرض تفاصيل الطلب
    • قبول الطلب وإنشاء الحساب
    • رفض الطلب مع إضافة ملاحظات
    • تصفية الطلبات حسب الحالة (قيد الانتظار، مقبول، مرفوض)
2. عرض الشبكات ومدراء الشبكة
  • المسار: /SystemAdmin/NetworksAndAdmins
  • الوصف: عرض جميع الشبكات المسجلة مع معلومات مديريها
  • المعلومات المعروضة:
    • اسم الشبكة وحالتها
    • مدير الشبكة المسؤول
    • عدد المخدمات
    • عدد القطاعات
    • عدد العملاء
    • مديري الشبكة غير المرتبطين بشبكة
الحساب الافتراضي:
اسم المستخدم: admin
كلمة المرور: admin
البريد الإلكتروني: admin@radatik.com

3.2 مدير الشبكة (NetworkAdministrator)

الدور: يدير شبكة واحدة أو أكثر، ويدير جميع العمليات داخل شبكته.

الصلاحيات:

  • إنشاء وإدارة الشبكات
  • إدارة المخدمات (MikroTik Servers)
  • إدارة القطاعات (Sectors)
  • إدارة المستقبلات (Receivers)
  • إدارة العملاء (Clients)
  • إدارة البروفايلات (Profiles)
  • إدارة المستخدمين (Employees, Clients)
  • إدارة طلبات الانضمام
  • إدارة طلبات تغيير السرعة
  • إدارة طلبات الصيانة
  • عرض لوحة التحكم والإحصائيات

الوظائف المتاحة:

الوحدة المسار الوصف
إدارة الشبكات /Network إنشاء وإدارة الشبكات الخاصة
إدارة المخدمات /MikroTikServers إضافة وإدارة مخدمات MikroTik
إدارة القطاعات /Sector إدارة القطاعات الجغرافية
إدارة المستقبلات /Receiver إدارة المستقبلات المرتبطة بالقطاعات
إدارة العملاء /Clients إدارة كاملة للعملاء واشتراكاتهم
إدارة البروفايلات /Profile إدارة بروفايلات الاشتراك
إدارة المستخدمين /Admin إدارة المستخدمين داخل الشبكة
إدارة الطلبات /JoinRequests
/RequestsManagement		 إدارة جميع أنواع الطلبات
لوحة التحكم /Home/AdminDashboard عرض إحصائيات شاملة للشبكة

3.3 الموظف (Employee)

الدور: يساعد مدير الشبكة في إدارة العمليات اليومية.

الصلاحيات:

  • إدارة العملاء (إضافة، تعديل، عرض)
  • إدارة طلبات الانضمام
  • إدارة طلبات تغيير السرعة
  • إدارة طلبات الصيانة
  • عرض لوحة التحكم
  • لا يمكنه حذف العملاء
  • لا يمكنه إدارة المخدمات
  • لا يمكنه إدارة البروفايلات
  • لا يمكنه إدارة المستخدمين

الوظائف المتاحة:

  • إدارة العملاء: /Clients - عرض، إضافة، تعديل، تجميد/تفعيل، تجديد الاشتراك
  • إدارة الطلبات: /JoinRequests و /RequestsManagement - معالجة جميع أنواع الطلبات
  • لوحة التحكم: /Home/EmployeeDashboard - عرض إحصائيات محدودة

3.4 العميل (Client)

الدور: يستخدم النظام لعرض معلومات اشتراكه وطلب الخدمات.

الصلاحيات:

  • عرض معلومات الاشتراك
  • طلب تغيير السرعة
  • طلب صيانة
  • عرض الباقات المتاحة
  • طلب الانضمام (إذا لم يكن لديه حساب)
  • لا يمكنه الوصول لإدارة النظام

الوظائف المتاحة:

  • لوحة التحكم: /Home/ClientDashboard - عرض معلومات الاشتراك
  • طلب تغيير السرعة: /ClientPortal/CreateSpeedChangeRequest
  • طلب صيانة: /ClientPortal/CreateMaintenanceRequest
  • عرض الباقات: /ClientPortal/AvailablePlans
  • طلب الانضمام: /Public/JoinAsClient

5. دليل الاستخدام

5.1 للمستخدمين الجدد

تسجيل الدخول:

  1. افتح المتصفح وانتقل إلى صفحة تسجيل الدخول
  2. أدخل اسم المستخدم وكلمة المرور
  3. اختر "تذكرني" إذا أردت
  4. اضغط "تسجيل الدخول"

مدير النظام - أول خطوات:

  1. سجل الدخول باستخدام الحساب الافتراضي (admin / admin)
  2. ستنتقل تلقائياً إلى صفحة طلبات مديري الشبكة
  3. يمكنك قبول أو رفض طلبات إنشاء حساب مدير شبكة

مدير الشبكة - أول خطوات:

  1. بعد قبول طلبك من مدير النظام، سجل الدخول
  2. ستنتقل تلقائياً لصفحة إنشاء شبكة
  3. املأ بيانات الشبكة:
    • اسم الشبكة (يجب أن يكون فريد)
    • المحافظات
    • شعار الشبكة (اختياري)
    • حالة الشبكة
  4. بعد إنشاء الشبكة، يمكنك البدء في إضافة المخدمات والعملاء

5.2 العمليات الشائعة

إضافة عميل جديد:

  1. انتقل إلى /Clients/Create
  2. املأ البيانات المطلوبة:
    • الاسم الكامل
    • رقم الهوية
    • اسم المستخدم (يجب أن يكون فريد في MikroTik)
    • كلمة المرور
    • البروفايل
    • رقم الهاتف
    • العنوان
    • المستقبل المرتبط
  3. اضغط "حفظ"
  4. سيتم إنشاء الحساب في MikroTik تلقائياً

تجديد اشتراك عميل:

  1. انتقل إلى /Clients
  2. ابحث عن العميل
  3. اضغط "تجديد الاشتراك"
  4. حدد تاريخ الانتهاء الجديد
  5. اضغط "حفظ"

إضافة مخدم MikroTik:

  1. انتقل إلى /MikroTikServers/Create
  2. املأ بيانات المخدم:
    • الاسم
    • عنوان IP
    • المنفذ (افتراضي: 8728)
    • اسم المستخدم
    • كلمة المرور
    • الشبكة المرتبطة
  3. اضغط "اختبار الاتصال" للتحقق
  4. اضغط "حفظ"

مزامنة عميل مع MikroTik:

  1. انتقل إلى /Clients
  2. اختر العميل
  3. اضغط "مزامنة مع MikroTik"
  4. سيتم تحديث البيانات تلقائياً

6. الوحدات والوظائف

6.1 وحدة المصادقة (AccountController)

الوظيفة المسار الوصف الصلاحيات
Login GET/POST /Account/Login تسجيل الدخول عام
Logout POST /Account/Logout تسجيل الخروج مسجل دخول
RegisterNetworkAdmin GET/POST /Account/RegisterNetworkAdmin طلب إنشاء حساب مدير شبكة عام

6.2 وحدة إدارة العملاء (ClientsController)

الوظيفة المسار الوصف الصلاحيات
Index GET /Clients عرض قائمة العملاء NetworkAdministrator, Employee, Client (بياناته فقط)
Create GET/POST /Clients/Create إضافة عميل جديد NetworkAdministrator, Employee
Edit GET/POST /Clients/Edit/{id} تعديل بيانات عميل NetworkAdministrator, Employee
RenewSubscription GET/POST /Clients/RenewSubscription/{id} تجديد اشتراك عميل NetworkAdministrator, Employee
SyncWithMikroTik POST /Clients/SyncWithMikroTik/{id} مزامنة بيانات عميل مع MikroTik NetworkAdministrator, Employee

6.3 وحدة إدارة المخدمات (MikroTikServersController)

الوظيفة المسار الوصف الصلاحيات
Index GET /MikroTikServers عرض قائمة المخدمات NetworkAdministrator
Create GET/POST /MikroTikServers/Create إضافة مخدم جديد NetworkAdministrator
TestConnection POST /MikroTikServers/TestConnection/{id} اختبار الاتصال بمخدم NetworkAdministrator
ActiveUsers GET /MikroTikServers/ActiveUsers/{id} عرض المستخدمين النشطين NetworkAdministrator

7. التثبيت والإعداد

7.1 المتطلبات

  • .NET 9.0 SDK
  • SQL Server 2019 أو أحدث
  • Visual Studio 2022 أو أحدث (اختياري)

7.2 خطوات التثبيت

1. استنساخ المشروع

git clone [repository-url] cd RadaTik

2. تحديث سلسلة الاتصال

  • افتح appsettings.json
  • حدّث ConnectionStrings:MyDBConnection

3. تطبيق Migrations

cd RadaTik dotnet ef database update

4. تشغيل المشروع

dotnet run

5. تسجيل الدخول

  • افتح المتصفح على https://localhost:5001
  • استخدم الحساب الافتراضي:
    • اسم المستخدم: admin
    • كلمة المرور: admin

7.3 الإعدادات الإضافية

تكوين MikroTik:

  1. تأكد من تفعيل API في MikroTik
  2. استخدم المنفذ 8728 (افتراضي)
  3. أنشئ مستخدم بصلاحيات كاملة

رفع الملفات:

  • تأكد من وجود مجلد wwwroot/uploads/networks/
  • تأكد من الصلاحيات الكافية للكتابة

الخلاصة

نظام RadaTik يوفر حلاً متكاملاً لإدارة مزود خدمة الإنترنت مع دعم كامل للتكامل مع MikroTik. النظام مصمم ليكون سهل الاستخدام وقوي الأداء وقابل للتوسع.
