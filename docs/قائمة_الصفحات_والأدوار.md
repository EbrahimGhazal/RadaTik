# قائمة صفحات المشروع والمسارات والأدوار

**المشروع:** RadTik  
**الرابط الأساسي:** `https://localhost:7098` (أو حسب منفذ التشغيل)

---

## الصفحة الرئيسية (توجيه حسب الدور)

| اسم الصفحة | الرابط | صاحب الدور | ملاحظات |
|------------|--------|------------|---------|
| لوحة التحكم (توجيه) | `/Home` أو `/` بعد تسجيل الدخول | أي مستخدم مسجل | يتم التوجيه حسب الدور: مدير النظام → SystemAdmin، مدير شركة → لوحة مدير الشركة، موظف → لوحة الموظف، نقطة تحصيل → CollectionPoint، عميل → ClientDashboard |

## 1. الحساب (Account)

| اسم الصفحة | الرابط | صاحب الدور |
|------------|--------|------------|
| تسجيل الدخول | `/Account/Login` | زائر (AllowAnonymous) |
| تسجيل الخروج | `/Account/Logout` (POST) | أي مستخدم مسجل |
| الملف الشخصي | `/Account/Profile` | أي مستخدم مسجل |
| رفض الوصول | `/Account/AccessDenied` | أي مستخدم مسجل |
| تسجيل موظف (من المدير) | `/Account/Register` | مدير الشركة (NetworkAdministrator) |
| طلب تسجيل مدير شركة | `/Account/RegisterNetworkAdmin` | زائر (AllowAnonymous) |
| نسيت كلمة المرور | `/Account/ForgotPassword` | زائر (AllowAnonymous) |
| تأكيد نسيت كلمة المرور | `/Account/ForgotPasswordConfirmation` | زائر (AllowAnonymous) |
| التحقق من رمز إعادة التعيين | `/Account/VerifyResetCode` | زائر (AllowAnonymous) |
| إعادة تعيين كلمة المرور | `/Account/ResetPassword` | زائر (AllowAnonymous) |
