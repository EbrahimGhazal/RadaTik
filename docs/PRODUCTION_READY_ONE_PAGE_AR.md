# RadaTik صفحة واحدة للنشر (وقت نافذة الإصدار)

استخدم هذه الورقة المختصرة أثناء نافذة النشر.

## قبل النشر (إلزامي)

- البناء: `PASS`
- الاختبارات: `PASS`
- نسخة احتياطية لقاعدة البيانات: `DONE`
- حزمة التراجع: `READY`
- تحديد مسؤول التراجع: `YES`

إذا أي بند غير مكتمل: **NO-GO**.

## خطوات النشر (T0)

1. إعلان بدء النشر.
2. نشر حزمة الإصدار.
3. تنفيذ smoke checks:
   - `/health` = `200`
   - تسجيل الدخول يعمل
   - تدفق عمل أساسي واحد يعمل

## فحص مباشر (أول 15 دقيقة)

- لا توجد قفزة في أخطاء `Unhandled exceptions`.
- لا توجد قفزة في `DB timeout/deadlock`.
- اتصال MikroTik مستقر.
- عمليات المحفظة/الفوترة تُكتب بشكل صحيح.

## قرار Go/No-Go

- `GO` عند نجاح جميع البنود الإلزامية ونتائج smoke checks.
- `NO-GO` عند فشل أي بند إلزامي أو فشل smoke checks.

## محفزات التراجع الفوري

نفّذ rollback فورًا إذا حدث أي مما يلي:

- عدم استقرار health endpoint.
- فشل تسجيل الدخول أو تدفق حرج.
- اكتشاف عدم اتساق مالي في البيانات.
- تكرار أخطاء حرجة في السجلات.

## سجل سريع

```text
معرف الإصدار:
بداية النشر (UTC):
نهاية النشر (UTC):
القرار: GO / NO-GO
المعتمد من:
هل تم استخدام التراجع: YES / NO
ملاحظات:
```
